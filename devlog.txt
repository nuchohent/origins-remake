OriginsX — Dev Log
==================

[19.08.2026] — Версия 1.8.0 / Race API 0.4.0

Четыре новых типа способностей:

DamageImmunityPower — пассивная иммунитета к урону по типу. Отменяет урон через хук onHurt, возвращая 0. Поддерживает 17 типов урона (огонь, лава, молния, взрыв, падение, утопление, яд и др.).

GrantItemPower — пассивная выдачи стартового предмета. Выдаёт предмет при onAttach через giveItemStack + начисление опыта для обновления инвентаря. Fallback на drop() при полном инвентаре. Поддерживает 26 ванильных предметов + любой по ID.

SummonPower — активная призыва мобов. Спавнит через EntityType.spawn() с EntitySpawnReason.MOB_SUMMONED. Кулдаун и количество настраиваются. Поддерживает 22 моба + любой по ID.

OnInteractPower — пассивная ПКМ-триггер. Срабатывает на onInteractBlock и onInteractEntity. 3 действия: эффект (MobEffectInstance), лечение (heal), урон (hurt).

Новые хуки в Power.java:

onInteractBlock(player, hand, pos, hitResult) и onInteractEntity(player, hand, target) — дефолтные реализации без изменений. NeoForge event listeners: PlayerInteractEvent.RightClickBlock и PlayerInteractEvent.EntityInteract в RaceAPI.java.

Расширение креатора:

5 новых атрибутов: armor_toughness, attack_reach, fly_speed, gravity, block_interaction_range. 7 новых эффектов: absorption, conduit_power, glowing, unluck, bad_omen, hero_of_the_village, weakness. onSelect/onDeselect: эффект теперь через выпадающий список с 12 вариантами вместо текстового поля.

Новая способность — Дальность рук (Reach):

Пассивная способность в RaceAPI (ReachPower.java). Увеличивает дальность взаимодействия с блоками и сущностями через нативные атрибуты minecraft:block_interaction_range (база 4.5) и minecraft:entity_interaction_range (база 3.0). Параметр reach_multiplier (DOUBLE, по умолчанию 1.0) с операцией ADD_VALUE. Не требует привязки к слоту — имеет binding = false. Зарегистрирована как PowerTypeSpec.REACH в создателе рас с параметром reach_multiplier.

Исправление краша Scissor:

При скролле списка способностей в создателе рас до конца, игра крашилась с ошибкой IllegalArgumentException: Scissor size must be >0, was 1635x0. Причина — LDLib2 26.2.2.35 добавил строгую валидацию в RenderPass.enableScissor(), а его mixin scissorPrecisely передавал 0-height viewport в этот метод. Создан mixin RenderPassMixin в OriginsX, который перехватывает enableScissor через @Inject at HEAD и отменяет вызов при размере scissor <= 0. Безопасно — при 0px scissor всё равно ничего не видно.
