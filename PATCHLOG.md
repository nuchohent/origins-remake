# OriginsX + Race API — Patch Notes

## v1.8.1 / v0.4.1 (26.2)

### OriginsX 1.8.1

#### Исправления
- **Ограничения атрибутов в создателе рас** — добавлена карта `ATTR_CONSTRAINTS` для 13 атрибутов с диапазонами min/max/base и подсказками. `movement_speed` ограничен диапазоном -0.5..2.0 (база 0.1, поэтому +2.0 = 21x скорость). Подсказка «Base: 0.1 — +2.0 = 21x» на трёх языках
- **Динамическое обновление параметров** — `refreshAttributeParams()` пересоздаёт поле количества с учётом ограничений выбранного атрибута. Автоматически срабатывает при выборе атрибута из выпадающего списка
- **Локализация** — добавлен ключ `originsx.creator.hint.movement_speed` в en_us, ru_ru, uk_ua

#### Удалено
- **Отдельный мод racecompat** — исправление респавна теперь встроено в Race API (см. 0.4.1)

---

### Race API 0.4.1

#### Исправления
- **Respawn handler** — `PlayerRespawnEvent` обработчик встроен в jar через отдельный `@Mod` класс `RaceAPIRespawnFix` с рефлексивным вызовом `RaceManager.applyPersistedRace()`. Оригинальные class-файлы не модифицированы (ASM не используется)
- **matchesEntityType** — null-проверка для `PlayerEntity` и `OtherEntity` перед вызовом `getType()`
- **tryParse** — null-валидация для `JsonObject` параметра
- **cooldownMap** — утечка памяти исправлена: кулдауны очищаются при снятии способности в `onRemove()`
- **GrantItemPower** — дубликаты предметов при релоге исправлены: `onAttach` проверяет наличие предмета перед выдачей
- **Mining Fatigue** — дублирующийся эффект `MINING_FATIGUE` вместо `DIG_SLOWDOWN` исправлен
- **Spawn truncation bias** — исправлено округление позиции спавна

---

### Race API 0.3.0 (легаси-порт)
- **Респавн-фикс** — исправлена потеря расы при смерти: `PlayerRespawnEvent` обработчик добавлен через инжекцию `RaceAPIRespawnFix.class` в jar без ASM-патчинга. Добавлен второй `[[mods]]` блок в `neoforge.mods.toml`. Оригинальные class-файлы не изменены

## v1.8.0 / v0.4.0 (26.2)

### OriginsX 1.8.0

#### Новые способности (4)
- **Иммунитет к урону (Damage Immunity)** — пассивная, полная отмена урона по типу. 17 типов: огонь, лава, молния, взрыв, падение, утопление, застревание в блоке, утонув в лаве, смерть от магмы, яд, высыхание, урон от крипера, выстрел скелета, урон в 바ли, рассекающий удар, конец-железа, провал
- **Стартовый предмет (Grant Item)** — пассивная, выдаёт ванильный предмет при выборе расы. 26 предметов + любой по ID через слот "Другой предмет". Стак до 64
- **Призыв (Summon)** — активная, призывает мобов рядом с игроком. 22 моба + любой по ID. Настраиваемые кулдаун и количество
- **При взаимодействии (On Interact)** — пассивная, срабатывает при ПКМ по блоку или entity. 3 действия: наложение эффекта (12 эффектов), лечение (настраиваемое количество), урон (настраиваемое количество)

#### Расширенный создатель рас
- **5 новых атрибутов:** бронепробиваемость, дальность атаки, скорость полёта, гравитация, дальность взаимодействия с блоками
- **7 новых эффектов:** поглощение, сила водного дыхания, свечение, невезение, дурная примета, герой деревни, слабость
- **Новые параметры для onSelect/onDeselect:** эффект (выпадающий список вместо текстового поля), длительность, amplifier

### Race API 0.4.0

#### Новые способности (4)
- **DamageImmunityPower.java** — пассивная, отменяет урон по типу через хук `onHurt`. Реализует `ServerPlayer.isDeadOrDying()`
- **GrantItemPower.java** — пассивная, выдаёт предмет через `onAttach` + начисление опыта для обновления инвентаря. Fallback на `drop()` при полном инвентаре
- **SummonPower.java** — активная, спавнит мобов через `EntityType.spawn()` с `EntitySpawnReason.MOB_SUMMONED`. Кулдаун через `%d тиков`
- **OnInteractPower.java** — пассивная, срабатывает на `onInteractBlock` / `onInteractEntity`. 3 действия: эффект (MobEffectInstance), лечение, урон

#### API
- **Новые хуки в Power.java:** `onInteractBlock(player, hand, pos, hitResult)`, `onInteractEntity(player, hand, target)` — дефолтные реализации без изменений
- **NeoForge event listeners в RaceAPI.java:** `PlayerInteractEvent.RightClickBlock` → `onInteractBlock`, `PlayerInteractEvent.EntityInteract` → `onInteractEntity`

### OriginsX 1.7.0

#### Новый дизайн интерфейса — Cyberpunk
- **Полный редизайн всех экранов** в стиле киберпанек: тёмные фоны с неоновыми акцентами (cyan, purple, pink, green)
- **CyberpunkTheme.java** — централизованная палитра и фабрики текстур/стилей для всех компонентов
- **Glow-эффект выбранной расы** — неоновая cyan-рамка вокруг выбранной расы в списке
- **Эффект наведения** — кнопки рас подсвечиваются при наведении курсора
- **Строка названия расы** — крупный заголовок и подзаголовок с дескриптором (Адаптация / Кастомная раса)
- **Декоративные линии** — горизонтальные разделители с градиентом (cyan → transparent)
- **HUD миникарта** — переработан в стиле худ-панели с прозрачным фоном и скроллом
- **Панель создания рас** — фон, кнопки, текстовые поля и выпадающие списки в киберпанек стиле
- **Тост-уведомления** — цвета неонового cyan и pink вместо стандартных
- **Панель гайда** — заголовок с градиентной линией, кнопки в стиле RECT_RD
- **Проблема со скроллом** — исправлен viewport в RaceInfoHUD: `overflow(Overflow.HIDDEN)` предотвращает краш при скролле

#### Новые способности (1)
- **Дальность рук (Reach)** — пассивная способность, увеличивает дальность взаимодействия с блоками и сущностями через нативные атрибуты `block_interaction_range` и `entity_interaction_range`. Параметр `reach_multiplier` (множитель, по умолчанию 1.0)

#### Техническое
- **Mixin для исправления краша скролла** — `RenderPassMixin` перехватывает `RenderPass.enableScissor()` и отменяет вызов при размере scissor ≤ 0, предотвращая `IllegalArgumentException: Scissor size must be >0, was 1635x0`
- **Обновление LDLib2 до 26.2.2.35** — улучшенная валидация scissor, исправления утечек рендеринга, тестовый UI harness

#### Исправления
- **Кейбинды в отдельной категории "OriginsX"** — все клавиши мода теперь в своей категории, а не в "Misc"
- **Регистрация кейбиндов** — исправлена регистрация через MOD bus (RegisterKeyMappingsEvent)
- **ConditionalPower: баг со скоростью** — силы, зависящие от условий, больше не "застревают" после смены расы
- **ConditionalPower: корректное включение/выключение** — теперь при переключении состояния условия вызывается `onAttach`/`onRemove` у внутренней способности
- **Категории условий** — новые условия (below_y, above_y) теперь показывают поле порога в создателе рас
- **Нехватка перевода** — добавлен ключ `originsx.creator.power.description`
- **Множество полей перевода** — 167+ ключей переведены для новых способностей

#### Новые способности (ранее добавленные в 1.6.0)
- **Телепорт-удар (Teleport Strike)** — телепортирует к ближайшему существу в направлении взгляда, наносит урон и вызывает тошноту
- **Землетрясение (Earthquake)** — AoE-удар: наносит урон, подбрасывает и замедляет врагов рядом. Бьёт по себе
- **Теневой шаг (Shadow Step)** — телепортирует за спину ближайшего существа, наносит удар в спину и накладывает слабость
- **Контроль размера (Size Control)** — изменяет размер персонажа по нажатию клавиши. В постоянном режиме — переключатель, во временном — действует заданное время

#### Новые условия (7)
- Плавание (is_swimming)
- Дождь (is_raining)
- Ниже Y (below_y)
- Выше Y (above_y)
- Падение (is_falling)
- Броня (has_armor)
- Полное здоровье (is_full_health)

### Race API 0.3.2

#### Новые способности
- **ReachPower.java** — пассивная сила дальности рук, использует нативные атрибуты `Attributes.BLOCK_INTERACTION_RANGE` (база 4.5) и `Attributes.ENTITY_INTERACTION_RANGE` (база 3.0). Параметр `reach_multiplier` (DOUBLE, по умолчанию 1.0) с операцией `ADD_VALUE`. Не требует привязки к слоту (`hasBinding() = false`)

#### Исправления
- **ConditionalPower.onAttach** — применяет внутреннюю/отрицающую способность в зависимости от текущего состояния условия, а не обе сразу
- **ConditionalPower.onTick** — теперь отслеживает переключение состояний и корректно вызывает `onAttach`/`onRemove`
- **ConditionalPower.onRemove** — снимает только активную в данный момент способность
- **setRace** — использует ATTACHED_RACES вместо getRace() для корректного поиска старой расы после перезагрузки датапаков
- **clearAllRaceEffects** — удаляет эффекты NAUSEA и WEAKNESS, вызывает removeRacePowers для старой расы

#### Новые условия в Conditions.java
- `is_swimming`, `is_raining`, `below_y`, `above_y`, `is_falling`, `has_armor`, `is_full_health`
