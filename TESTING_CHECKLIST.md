# Тестирование способностей — Чеклист

Для каждой способности:
1. Создать расу с этой способностью через создатель
2. Выбрать расу
3. Проверить в игре
4. Отметить результат

## Пассивные (атрибуты)
- [ ] **AttributePower (max_health)** — HP изменилось?
- [ ] **AttributePower (attack_damage)** — урон изменился?
- [ ] **AttributePower (movement_speed)** — скорость изменилась? (база 0.1!)
- [ ] **AttributePower (armor)** — броня изменилась?
- [ ] **AttributePower (knockback_resistance)** — сопротивление отбрасыванию?
- [ ] **ToughnessPower** — толщина изменилась?
- [ ] **StepHeightPower** — высота шага увеличилась?
- [ ] **ReachPower** — дальность рук увеличилась?

## Пассивные (эффекты)
- [ ] **StatusEffectPower** — эффект накладывается при выборе расы?
- [ ] **EffectRemovalPower** — эффект снимается?
- [ ] **LightSensitivePower** — урон при ярком свете?

## Активные
- [ ] **DoubleJumpPower** — двойной прыжок работает?
- [ ] **WallJumpPower** — прыжок от стены работает?
- [ ] **BlinkPower** — телепорт вперёд работает?
- [ ] **DashPower** — рывок работает?
- [ ] **PhaseDashPower** — фазовый рывок сквозь стены?
- [ ] **SprintJumpPower** — прыжок во время бега?
- [ ] **BouncyPower** — прыгучесть работает?
- [ ] **OverdrivePower** — ускорение при включении?

## После всех — проверки респавна
- [ ] Умереть с каждой расой → раса сохраняется?
- [ ] Выйти → зайти → раса на месте?
- [ ] Сменить измерение → раса сохраняется?
