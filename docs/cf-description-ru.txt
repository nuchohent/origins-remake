[b]Русский (RU)[/b]

OriginsX — система рас в духе Origins для Minecraft [b]26.2 (NeoForge)[/b]. При первом заходе открывается экран выбора: иконка, сложность, описание, живой анимированный превью твоего скина и список сил расы.

[list]
[*][b]Выбор расы[/b] — состояние сохраняется при смерти, релоге и смене измерений.
[*][b]Создатель рас без кода[/b] — вкладка Create Race: имя, иконка, сложность −5..+5, силы из ~60 типов-шаблонов, 50 условий с AND/OR/NOT, живой балансометр подскажет, если раса перекачана.
[*][b]Шеринг рас[/b] — кнопка «Поделиться» даёт компактную строку ORX1:...: кинь её другу для импорта в один клик или оператору сервера — он импортирует расу, и она появится у всех игроков.
[*][b]Выделенные серверы поддерживаются полностью[/b] — список рас синкается с сервера автоматически.
[*][b]Датапаки и API[/b] — свои расы и силы в JSON (см. гайды в галерее изображений), для моддеров — Java API.
[*][b]Аддон Skill Tree[/b] — отдельный мод с деревьями навыков для рас.
[/list]

[b]Установка[/b]: Minecraft 26.2 + NeoForge 26.2.0.67+, обязательно [b]Race API 0.7.6+[/b] (в паре с 0.7.5 на серверах список рас будет пуст), рекомендуется LDLib2.

[b]Клавиши[/b] (настраиваются): O — HUD расы, J — настройки HUD, активные силы — до 9 слотов (по умолчанию V).

[b]Команды[/b]: /raceapi list | set | clear, /originsx set | clear | open

Мод только для Minecraft 26.2 — портов под другие версии нет.
