## Новое: четвёртый мод «OriginsX Looks» (внешность) — v1.0.0, локальная сборка

- Идея: крепление предметов на кости персонажа (рога из стержня Энда под 45° и т.п.)
- Хранение: массив `cosmetics` прямо в JSON расы → синк бесплатно; рендер-слой на игроках (видят все)
- Редактор: форма (пикер предмета, кость, pos/rot/scale) + ЖИВОЕ превью на себе без сохранения (клиентский override); сохранение пишет файл расы + /reload
- Кнопка «Внешность» в панели кастомной расы, только при установленном аддоне
- RaceAPI получил `Race.getSourceJson()` (исходный JSON расы доступен клиенту)
- НОВЫЙ сетевой пакет `originsx_looks:player_race` (S2C broadcast uuid→raceId) — косметика рендерится и на других игроках
- **Роадмап v2**: drag прямо во 3D-вьюпорте (LDLib2 Scene); **идея автора**: выбор модели СУЩНОСТИ вместо модели игрока (полное превращение — рендер чужой модели на игроке)
